# Sweet Project – Online Ordering Platform for Local Cookies Bakery

## Summary
Custom-built web platform for a local bakery to showcase products, handle online orders, and improve brand visibility.

## Tech Stack
Next.js, React, Tailwind CSS

## Key Features
- Fully responsive UI for mobile and desktop
- Product gallery with optimized images (Next/Image)
- SEO-optimized pages for local Google search

## Performance Highlights
- Lighthouse Performance score: 98/100
- Reduced page load time from 3.5s to 1.1s
